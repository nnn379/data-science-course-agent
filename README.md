# 数据科学导论课程智能体

这是一个不依赖构建工具的前端原型，包含学生端与教师端两套入口，以及五个独立的课程智能体服务界面。

## 本地预览

在项目目录运行 `python -m http.server 4173`，然后访问 `http://localhost:4173`。

## 接入 Dify

打开 `dify.config.js`，将 Dify 应用在“发布 → 嵌入网站”中提供的 URL 填入对应栏目：

- `study`：智能伴学中心
- `personal`：个性化学习
- `design`：教学设计辅助
- `case`：课程案例生成
- `grading`：作业批改辅助

URL 留空时自动显示内置交互演示；填入后，该栏目会切换为对应的 Dify 聊天界面。
